# About
Jaber plugin to add a toggleable revision history as a column type to the backend.




## Usage

To add a revision column to a list; set the `type` of the column to `jaber-list-revision-history`. 

Example:
```yaml
jaber-list-revision-history:
        label: old_changes
        span: auto
        type: jaber-list-revision-history
        searchable: false
        sortable: false
```
